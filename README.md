# ATM Transaction SQL Project

## Project Description
This project is an ATM Transaction Database developed using SQL.

## Objectives
- Store and manage ATM transaction data
- Analyze customer transactions
- Find total deposits and withdrawals
- Identify transaction patterns

## SQL Concepts Used
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- CASE
- JOIN
- Subqueries
- Window Functions

## Project Analysis
This project uses SQL queries to analyze ATM transactions and generate useful insights from the database.
